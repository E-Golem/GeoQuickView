## 1. 用户已经确认的要求

| 项目 | 已确认内容 |
| --- | --- |
| 使用方式 | Windows 桌面程序，离线使用，解压或安装后可以直接打开 |
| 核心用途 | 快速、直观地查看地理数据属性及可视化，统一查看 TIF、NC 和常见 GIS 矢量 |
| TIF 规模 | 通常单波段不超过 1 GB；多波段文件的总大小可能很大 |
| 空间规模 | 一般不超过中国范围、约 500 m 分辨率的栅格规模；尚无精确宽高上限 |
| NC 类型 | 常见气象变量，通常不超过 50 个变量；这不是时间步数、垂直层数或维度轴数的上限 |
| 处理优先级 | 先完成主要查看功能；重投影作为首个处理功能；其它处理功能放到后续版本 |
| 简易出图 | 通用研究区模板：当前图层、可选边界、标题、色标、经纬网、比例尺 |
| 出图参数 | 可调范围、配色、字体、尺寸和 DPI，导出 PNG、PDF |
| 目标仓库 | https://github.com/E-Golem/GeoQuickView |
| 开发前约束 | 用户要求先明确需求与方案，不直接开始开发；尚待确认技术路线并进入开发 |

NC 文件大小、时间步数、垂直层数、网格结构及电脑配置仍未知。它们影响性能验收，不能把“50 个变量”理解为小文件保证。未提供的信息可以在开发获准后通过代表性文件确认，无需为此阻止当前方案收敛。

## 2. 技术路线建议

建议采用 **Python + PySide6 / Qt Widgets 的 Windows 原生桌面程序**，界面采用中文，交付可直接运行的桌面发行包。中文界面为建议默认项。

| 组件 | 职责 | 选择理由与约束 |
| --- | --- | --- |
| PySide6 | 窗口、拖放、图层面板、属性表、后台任务状态 | Qt 官方 Python 绑定；不需要浏览器或用户自行启动本地服务 |
| GDAL / OGR / OSR | 栅格与矢量读写、空间参照、窗口读取、重投影 | 复用成熟驱动与坐标变换；发行包必须核查实际可用驱动与投影资源 |
| xarray + netCDF4 | NC 变量、维度、切片、时间和 CF 元数据 | 保留多维语义；先选择二维切片再读取，避免全文件转为 NumPy 数组 |
| NumPy + PyQtGraph | 预览色带、拉伸、直方图和交互画布 | 显示有上限的预览数组；地理定位与坐标变换由地理数据层承担 |
| Matplotlib + Cartopy | 通用地图模板与 PNG/PDF 导出 | 出图模块按需加载，避免阻塞基础属性查看；离线资源需随包准备 |

暂不引入完整 QGIS 运行时、浏览器服务、插件框架或自研格式解析器。GDAL 已覆盖的读写与投影功能优先使用 GDAL，避免同一职责同时堆叠多套地理库。

C++ + Qt 是可行备选，但目前没有性能证据要求整个应用使用 C++。先以按需读取和独立发行包的实际表现验证 Python 路线；如果具体瓶颈确实存在，再对瓶颈选择实现方式。

打包工具在开发阶段通过实际依赖集验证后确定。Qt 官方提供 pyside6-deploy，也列出了其它打包工具；这不证明任意工具都能自动完整收集 GDAL、PROJ、NetCDF 和地图资源。发行包必须在没有开发环境的 Windows 上验证。

## 4. 第一版功能范围

### 4.1 打开与属性查看

- 支持拖放和文件选择，区分文件、栅格波段、NC 变量及矢量图层。
- 栅格显示格式、磁盘大小、宽高、波段、数据类型、坐标系、范围、X/Y 分辨率及单位、NoData、单位、缩放因子与偏移量、概览与统计状态。
- NC 显示全局属性、变量清单、变量单位/属性、维度及坐标；变量数与时间/层次数分别展示。
- 矢量显示坐标系、几何类型、图层及字段；要素计数、范围等可能需要扫描的操作不在打开时强制全量计算。
- 保留原始元数据查看入口。未知坐标系显示为未知，不能静默指定为 EPSG:4326。

### 4.2 可视化

- 单波段伪彩色、多波段切换、RGB、可调色带与拉伸、NoData 透明显示。
- 缩放、平移、适配范围、图层开关/顺序/透明度、矢量边界叠加、像元或要素查询。
- 像元查询回到原始分辨率读取，并区分原始存储值和应用缩放后的物理值；不能把预览插值结果当作原始像元值。
- 图层叠加采用一致的空间参照。预览重投影与改变输出文件坐标系是两个不同操作。
- NC 提供变量选择，以及按实际维度生成的时间、垂直层等切片控件；按需显示当前二维切片。
- 气象 NC 重点验证升降序纬度、0–360 与 -180–180 经度、缺失值、scale_factor/add_offset、时间单位和日历、CF grid_mapping。
- 在代表文件核查前，不宣称所有曲线网格、非结构网格和未带坐标的数组都能正确显示为地图；应报告实际能力和限制。

### 4.3 重投影试点

- 用户选目标坐标系、输出路径及重采样方式，输出新文件并可加载查看。
- GeoTIFF 明确选择当前波段或全部选定波段；不能隐式处理大文件内的所有波段。
- 矢量重投影复用 OGR 坐标变换/转换功能；输出格式与字段保留需验证。
- NC 仅在选定二维切片的地理定位得到确认后进入地理重投影流程；其余情况给出清楚的原因。
- 显式区分“指定源坐标系”和“重投影”，避免把更改坐标标签当作变换坐标。
- 连续量与分类值使用适合的数据重采样方式；保留并验证 NoData、单位、数据类型及缩放语义。
- 长任务显示进度、支持取消；输出完成后才作为成功结果展示。默认使用独立输出，不覆盖输入。

### 4.4 通用地图模板

- 当前图层与可选边界，标题、色标、经纬网、比例尺。
- 调整地图范围、配色/数值范围、字体、页面尺寸、DPI，导出 PNG 与 PDF。
- 预览与导出使用同一套范围、坐标系、波段/变量/切片、NoData 和色带参数。
- 比例尺依据投影和地理距离计算，不能把角度直接标成米；不适用的场景应明确提示。
- 字体、投影资源及模板所需边界必须可在离线环境使用；基础流程不能依赖首次联网下载。

### 4.5 后续版本

范围/矢量裁剪、格式转换、独立重采样、NoData/缺失值处理按用户要求安排到后续版本。本轮不将它们列作第一版必须完成的独立工具。时序统计、栅格计算器等尚未被用户选入范围。

## 5. 格式支持与能力边界

第一版重点验证 GeoTIFF/TIFF、NetCDF、Shapefile、GeoJSON、GeoPackage。每种格式分别记录属性、预览、处理和导出能力，不能用“GDAL 支持”替代发行包的逐项验证。

VRT、HDF、IMG、JP2、GRIB、CSV 点数据、Zarr 等可作为后续扩展候选；它们需要用户优先级和实际样例，不以本节列举视作已经实现或已保证支持。

Shapefile 作为多文件数据集处理；GeoPackage 允许多个图层；NC 不把扩展名直接等同于规则经纬网。

## 6. 轻量与速度的实现约束

1. 先读属性，再读当前预览，避免打开文件时计算所有波段/变量的统计。
2. 栅格按当前视窗和显示分辨率读取；有概览时利用概览。没有概览的压缩文件仍可能需要较多底层读取，不能保证所有文件都能瞬间打开。
3. 精确统计、抽样统计、已有缓存统计与当前视窗统计分别标注来源和范围。NC 存储元数据里的 valid_min/valid_max 不等于实测值范围。
4. 多波段 TIF 按当前波段或 RGB 组合读取，NC 按变量和二维切片读取，内存使用与正在显示的数据相关。
5. 后台任务有上限；切换文件、波段或时间时丢弃过时任务结果，保持界面可操作。
6. 查看输入时不自动创建或修改输入目录中的 .aux.xml/.ovr。应用缓存与科研原始文件分开；主动建立概览属于显式操作。
7. 缓存区分文件身份、大小、修改时间、波段/变量/切片、空间范围、统计模式和显示参数；输入变化时失效。旧报告不能证明当前文件仍相同。
8. Matplotlib/Cartopy 等出图依赖按需加载。软件包大小、冷启动、内存峰值均由实际打包测试报告，不预先宣称固定数字。

## 7. 验收方式

获准开发后先建立一组可复现的代表文件和基准，再确认性能阈值。未实测前，不作“秒开任意 1 GB 文件”的承诺。

| 范围 | 需要的证据 |
| --- | --- |
| 属性正确 | 同一文件与 GDAL/OGR、NC 原始属性交叉核对；未知值、单位、统计来源不混淆 |
| 地理位置正确 | 用已知范围、坐标点及边界核对；含不同坐标系叠加、非正方形像元和必要的旋转情况 |
| NC 正确 | 多变量、多时间/层、缺失值、缩放值、经纬度方向和日历案例；记录网格结构限制 |
| 多波段与大文件 | 打开/切换时的读取范围、首次预览时间及内存峰值；核实不全量读取所有波段 |
| 重投影正确 | 输出坐标系、范围、分辨率、NoData、数值/分类保持情况与独立参照结果一致 |
| 出图正确 | PNG/PDF 实际打开检查：范围、色标/单位、比例尺、中文字体、边界和布局 |
| 发行可用 | 在无 Python、无 QGIS/ArcGIS 的干净 Windows 环境中，断网完成打开、查询、重投影和导出 |
| GitHub 交付 | 本地提交历史、远程分支对应的提交、可取得的源码/文档及 Windows 发行文件 |

记录冷启动和重复打开的区别、硬件与存储位置、有无概览、文件压缩/分块方式、变量/波段/切片、时间及内存。性能阈值待代表文件和机器配置确认。

## 10. 技术依据

- [Matplotlib savefig](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.savefig.html)：图像和图形导出参数。
