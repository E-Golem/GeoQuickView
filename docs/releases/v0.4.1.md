# GeoQuickView v0.4.1

本版修复地图导出与重投影的保存位置问题。

- **默认导出到可写文件夹**：导出地图、重投影的保存对话框现在默认指向“文档\GeoQuickView 导出”（不可用时依次回退到用户目录、临时目录下的同名文件夹），不再默认写到程序所在目录或当前工作目录；便携版放在只读位置（如 Program Files）时也能正常导出。
- **不可写文件夹的处理**：选择没有写权限的文件夹时给出明确提示，并自动回到可写文件夹重新选择；后台任务遇到权限错误时显示“无法写入文件”和可用的默认文件夹，而不是原始的 `Permission denied`。
- **避免重名失败**：默认文件名自动避开已有文件（`名称.png`、`名称_1.png`……）；如果手动选择了已存在的文件，会提示换名而不是直接失败（导出与重投影都适用）。
- **无图层时给出说明**：没有可见图层且底图未启用时点击“导出地图”，提示需要先打开数据，而不是无反应。

验证为 31 项核心/健壮性测试与 28 组 Qt 界面检查全部通过；细节见 [docs/VALIDATION.md](../VALIDATION.md)。

下载完整 zip 后解压整个目录，双击 GeoQuickView.exe；保留 `_internal` 与 `share` 目录。`SHA256SUMS.txt` 用于核对下载文件。
