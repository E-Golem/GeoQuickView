# GeoQuickView v0.3.2

本版修复便携版首次解析坐标系时的 PROJ 错误。

- **问题**：便携版点击“加载合成演示数据”等操作弹出 `RuntimeError: PROJ: proj_create_from_database: Cannot find proj.db`。原因是 `proj.db` 被打包在 `_internal\Library\share\proj`，而 PROJ 按 `proj_9.dll` 的相对位置查找数据目录；此前只能依赖启动时把 PROJ 数据复制到可写的 ASCII 临时目录，复制失败或临时目录不可写时即报错。
- **修复**：打包后把 PROJ 数据放到 `share\proj`（与 `_internal` 同级），PROJ 无需任何环境变量即可找到；应用启动时依次在 `<bundle>\share\proj` 与 `Library\share\proj` 中查找，ASCII 路径直接使用，非 ASCII 路径仍镜像到临时目录作为后备。
- **防回归**：打包脚本校验该布局，便携包验证脚本解压后再次断言；并在“无任何可写临时目录”的条件下执行自检。

0.3.1 的三项修复（精确统计落入属性页、多图层独立渲染与缓存、NetCDF 重复端点/非均匀坐标预览）保持不变。验证为 23 项核心集成测试与 22 组 Qt 界面检查全部通过，另有便携包自检；细节见 [docs/VALIDATION.md](../VALIDATION.md) 与 [docs/issues.md](../issues.md)。

下载完整 zip 后解压整个目录，双击 GeoQuickView.exe；代码签名未提供，保留 `_internal` 与 `share` 目录。`SHA256SUMS.txt` 用于核对下载文件。
