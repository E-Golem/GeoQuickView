# GeoQuickView v0.3.1

本版处理用户反馈的三项问题，集中在预览响应、统计结果位置与 NetCDF 网格兼容性。

- **精确统计改到“属性”页**：统计结果写入属性树的「精确统计（全量，物理值）」节点并自动切换、定位、短时高亮；「查询」页只保留地图单击的像元/要素查询。切换波段、变量或切片后旧统计自动失效，避免误读。
- **多图层预览各自独立**：每个可见图层与省界底图各用一个后台任务渲染，先完成的先上屏；视窗不变时切换可见性、调整顺序直接复用缓存，立即生效。
- **过期渲染取消**：视窗或选择变化时取消上一代任务，GDAL 与 NetCDF 读取均响应取消；过期结果按代次丢弃。
- **加载状态可见**：未完成的图层在左侧标注「加载中…」，地图下方显示正在加载的图层；不再把上一代画面当作当前结果。
- **NetCDF 重复经度端点**：0–360 经度中与 0° 重复的 360° 列自动合并，仍按规则网格预览、查询与统计。
- **NetCDF 非均匀一维坐标**：拉伸纬度、不等间隔经度按等间距近似预览整体分布；查询与统计仍使用原始坐标。此类网格的重投影会明确拒绝并说明原因。

验证为 22 项核心集成测试与 22 组 Qt 界面检查全部通过，细节见 [docs/VALIDATION.md](../VALIDATION.md) 与 [docs/issues.md](../issues.md)。
