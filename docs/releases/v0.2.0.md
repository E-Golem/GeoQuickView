# GeoQuickView v0.2.0

本次更新改善属性查看与地图操作，并加入离线中国省界底图。

- 属性名称按内容调整列宽，支持手工调整、横向滚动和完整悬浮提示；双击属性或点击“查看选中属性全文”可查看、选择和复制长名称及完整值，包括统计量、WKT 和列表。
- 地图缩放设置最大和最小视野，随当前图层及地图坐标系更新；不会无限放大或缩小。栅格/NC 最小视野按数据尺寸限制，矢量按范围限制。
- 地图坐标轴与网格默认关闭，可用“坐标轴”开关显示；出图的经纬网仍由出图面板独立控制。
- 默认显示内置中国省界底图，支持显隐与地图投影转换；省界填充在数据下方，细边界在数据上方，方便定位。无空间参照的数据不会叠加地理底图。导出地图可包含或排除边界。
- 右上角改为 GitHub 仓库按钮，一键通过系统浏览器打开项目仓库；移除“离线桌面版”标识。

省界来源为用户提供的“中国标准地图-审图号GS(2020)4619号-shp格式/省界.shp”。34 个要素转换为 GeoPackage，保留几何、属性和原始北京 1954 Lambert 坐标系。来源与原文件 SHA-256 记录随包提供。

验证包括 19 项核心集成测试、20 组 Qt 界面检查，以及解压迁移后独立运行包的格式、底图、重投影和 PNG/PDF 自检。

下载 GeoQuickView-0.2.0-windows-x64.zip 后完整解压，双击 GeoQuickView.exe；无需安装 Python。保留 _internal 目录。SHA256SUMS.txt 用于核对下载文件。
